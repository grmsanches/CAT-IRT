- `enem_mt_2023.parquet`, `dados_eda.parquet`, `mat_2023.parquet` — existing generated artifacts, not verified as suitable for the consolidated pipeline. Retain until schemas, provenance, and overlap have been checked. Do not assume their presence proves source processing is reproducible.

`cat_results.csv` and `cat_summary.csv` are documented as outputs of the old command-line runner but were not present in the workspace inventory. Their absence should not be filled with invented results.

## Execution order

From the project directory, with original files at `../microdados_enem_2023/DADOS/`:

```sh
Rscript test_cat.R
Rscript prepare_enem.R
Rscript analyze_cat.R --replications=20 --n=50
quarto render interpretation.qmd
```

If the source directory is elsewhere:

```sh
Rscript prepare_enem.R --data-dir=/absolute/path/to/microdados_enem_2023/DADOS
```

Only after confirming parameter provenance, scale and logistic parameterization should the ENEM bank be enabled:

```sh
Rscript analyze_cat.R --replications=20 --n=50 --use-enem-bank=TRUE --scale-confirmed=TRUE
```

The flag `--scale-confirmed=TRUE` is an analyst assertion, not a software validation. The documentary evidence supporting it must be recorded alongside the analysis. The simulation remains conditional on its specified response model and is not observed adaptive-testing performance.
